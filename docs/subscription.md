# Подписка — построена, выключена

Подписка целиком написана, покрыта тестами и **выключена одним переключателем**.
Ничего не удалено: Stars, автопродление, отсрочка, возвраты, пейвол, панель
владельца и бесплатный дайджест лежат на месте и продолжают проверяться тестами.

Решение принято осознанно: чтобы продавать, нужно провести настоящий платёж и
настоящий возврат, а это решение про деньги, а не про код. Пока оно не принято,
полка просто открыта.

## Переключатель

```
PI_SUBSCRIPTION=on     # продаём
# любое другое значение, включая отсутствие строки — не продаём
```

В коде это `Config.subscription` (`pi/config.py`), по умолчанию `False`.

## Что меняется, когда выключено

| Место | Включено | Выключено |
|---|---|---|
| Витрина, `pi/web.py` `_paying` | 402 без подписки | открыта всем |
| Лента находок, `pi/personal.py` `subscribers` | только платящим | всем читателям |
| Меню бота, `menu_keyboard` | кнопка «💎 Подписка» | кнопки нет |
| `/subscription` | предложение или срок | «Подписки сейчас нет — всё открыто» |
| Кнопка `buy:` со старой клавиатуры | счёт в звёздах | вежливый отказ, счёт не выставляется |
| Дайджест, `pi/digest.py` `readers` | бесплатным, 2 в день | никому: рекламировать нечего |

## Чего не меняется

**Состояние оплат не стирается.** `bot_users.paid_until`, `stars_paid`,
`sub_charge_id` остаются как есть. `python -m pi grant`, `python -m pi subscriptions`
и панель владельца продолжают говорить правду. Включение подписки **возобновляет**
её, а не начинает с нуля: у кого доступ был, у того он и останется.

**Тесты не отключены.** Файлы `tests/test_payments.py`, `tests/test_subscribers.py`
и часть `tests/test_web.py` явно ставят `subscription=True` — они и существуют,
чтобы проверять включённое состояние. Отдельные классы `TestWithNothingBeingSold`
проверяют выключенное. То есть оба состояния под тестом одновременно, и правила,
охраняющие продаваемое, не сгниют, пока продажа на паузе.

## Как включить обратно

1. Проверить курс звезды к доллару при выводе через Fragment — от него зависит
   вся экономика в `docs/product.md`.
2. Написать условия возврата в `/terms` до первой продажи.
3. Добавить в `.env`:
   ```
   PI_SUBSCRIPTION=on
   ```
4. Перезапустить бота и витрину.
5. Пройти денежный путь целиком с тестового аккаунта: покупка → доступ открылся →
   `/cancel` → возврат `python -m pi subscriptions --refund <id>` → доступ закрылся,
   звёзды вернулись. Пошагово — в `docs/function-map.md`, раздел «Что может
   прогнать только владелец».
6. Поставить `python -m pi subscriptions` в расписание, иначе никто не узнает,
   что подписка кончается.

Пока шаг 5 не пройден на живых деньгах, подписку включать не стоит: всё остальное
проверено тестами, а платёж — нет.
